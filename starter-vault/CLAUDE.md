# Brain — knowledge vault

Entry point: [README.md](README.md) — read it first; it has the index.

To find anything here, run:

```
rg "^description:" <path-to-this-vault> -g "*.md"
```

then read the 1–5 notes whose description matched. That is the whole search story. Scope it to a
type folder (`.../lessons`, `.../machine`) once you know which kind of note you want — that is
what the folders are for.

Before writing or editing any note, read [CONVENTIONS.md](CONVENTIONS.md).

Two workflows, both skills in this vault:

- `capture` — one entry into [inbox.md](inbox.md). No frontmatter, no filing.
- `triage` — promote the inbox to real notes, once it holds ~5 entries.
